# Jungle 2.0.0 development plan

1. Freeze the profile bytes, WIT and portable fixtures from the brief. Change Red’s canonical starting position, draw adjudication and trap precedence. Check move generation and undo against the fixtures.
2. Share Rust rules, evaluation and search between the browser engine and the clock-free entrant. Bound the former from the UI request and the latter by counted visits. Measure against the pre-refactor search with colors exchanged.
3. Update the React game, setup, history, accessibility, saved-game replay and audio. Use the licensed animal counters on both boards, with a synchronous Rust renderer for Arena frames.
4. Build the component, hosted site and self-contained HTML together. Generate identity and release names from the same constants. Verify both SHA-256 values and the offline download.
5. Run an independent browser referee against the exact release bytes. Exercise both seats, self-play, flipped frames, direct replay seeks, terminal states, worker fallback and complete standalone games.
6. Commit the release files, deploy to the existing Cloudflare Pages project and verify the public download. Attempt public Arena admission when the upload interface is available. Record results and actual browser coverage with the release.
